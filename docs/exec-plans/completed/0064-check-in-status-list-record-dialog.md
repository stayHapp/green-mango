# 0064 签到状态列表与签到明细弹窗

## 任务名称

将签到场次列表改为简洁状态列表，并把签到记录明细改为弹窗查看。

## 背景

0063 的双栏布局中，签到场次列表仍然偏宽，挤压了右侧签到统计。用户确认新的状态列表效果图，并提出签到记录模块空间较小，应改为弹窗查看嘉宾签到明细。同时用户指出签到模式与场次个数存在业务关系。

## 目标

1. 将签到场次从宽表格改为简洁状态列表，重点呈现场次签到状态。
2. 右侧保留签到统计摘要、场次选择和“查看签到明细”入口。
3. 点击“查看签到明细”打开弹窗，在弹窗中展示签到嘉宾列表。
4. 页面中说明签到模式与场次个数的关系：
   - 单场签到：建议保留 1 个有效场次。
   - 按日期签到：建议场次数与会议自然日数量一致。
   - 自定义场次：允许 1 个或多个，由管理员维护。
5. 不自动删除已有场次，避免误删历史数据。

## 不在本次范围内

1. 不新增后端签到模式持久化字段。
2. 不改变签到统计接口结构。
3. 不实现拖拽排序。
