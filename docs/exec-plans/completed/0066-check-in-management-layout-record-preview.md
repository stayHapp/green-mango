# 签到管理布局与签到明细预览优化

## 任务名称

优化签到管理布局和签到明细预览。

## 背景

用户确认去掉签到统计上方的“当前签到规则”和“工作人员端当前签到场次”两个独立模块，将“按日期生成”和“新增场次”作为场次列表操作放到场次列表上方。同时，签到明细模块不再只显示空状态和按钮，而是在模块内固定展示所有签到人员列表，并提供放大图标进入完整弹窗。

## 用户确认状态

用户已确认执行该布局方案。

## 执行前必须读取

- `AGENTS.md`
- `frontend/src/views/admin/AdminMeetingDetailView.vue`
- `frontend/src/styles.css`
- `docs/exec-plans/completed/0065-check-in-mode-rule-correction.md`

## 目标

1. 删除签到管理顶部独立“当前签到规则”模块。
2. 删除独立“工作人员端当前签到场次”模块。
3. 将“按日期生成”“新增场次”按钮放到“签到场次”列表标题区上方/右侧。
4. 按钮名称分别改为“按日期生成”“新增场次”。
5. 签到明细模块固定展示当前场次签到人员列表，支持滚动查看。
6. 用放大图标打开完整签到明细弹窗，不再展示“查看签到明细”文字按钮。

## 不在本次范围内的内容

- 不修改后端签到规则。
- 不修改签到明细数据字段。
- 不新增分页接口；当前前端使用已加载明细进行滚动预览。
- 不做本地浏览器绕过验证。

## 技术决策与待确认项

- 场次规则状态保留在场次列表副标题中，避免用户失去“日期自动切换 / 手动覆盖 / 自定义”的上下文。
- 签到明细卡片内列表使用固定高度滚动，弹窗展示更完整字段。
- 放大入口使用图标按钮，放在签到统计标题区。
