# 新功能产品与设计文档补齐

## 任务名称

对齐近期新功能的产品、设计和架构文档。

## 背景

当前工作区相对上次提交已经新增多场次签到、日期场次自动切换、工作人员端连续扫码、结构化日程、会议资料多条目和附件等能力。部分正式产品文档仍把这些能力列为后续扩展，或仍保留“会议级唯一签到”“文件上传不做”等旧口径，需要补齐并消除矛盾。

## 用户确认状态

用户要求检查项目中的产品文档、设计文档等是否遗漏新功能，若有则补充。

## 目标

1. 检查产品、架构和设计相关文档对近期新功能的覆盖情况。
2. 修正仍把已实现能力列为后续扩展的旧口径。
3. 补充工作人员端连续扫码和当前场次提示说明。
4. 补充会议资料多条目、附件下载和受限文档编辑说明。
5. 补充结构化日程和后台签到管理布局说明。

## 不在本次范围内的内容

- 不修改业务代码。
- 不新增数据库迁移或接口。
- 不提交当前改动。

## 分步计划

1. 审查现有文档和近期执行计划完成记录。
2. 更新产品范围、功能地图和三端工作流。
3. 更新架构概览、后端规划、前端规划和安全原则中的旧口径。
4. 运行文档差异检查。

## 验收标准

- 文档不再把会议资料附件、多场次签到、结构化日程列为第一版不做或后续能力。
- 工作人员端文档体现当前签到场次提示和连续扫码交互。
- 嘉宾端文档体现会议资料附件下载和日期日程展示。
- 架构文档能反映新增模型、路由、服务和配置。

## 验证方式

- 使用 `rg` 检查关键旧口径。
- 运行 `git diff --check`。

## 风险与注意事项

- 当前工作区已有大量未提交代码和文档改动，本任务只修改文档。
- “PDF 在线预览、资料版本管理、离线签到、补签、撤销签到”仍属于后续能力，不应误写为已实现。
