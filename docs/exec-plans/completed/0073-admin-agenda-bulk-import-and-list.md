# 执行计划 0073：管理员端日程批量粘贴与列表化编辑

## 任务名称

管理员端日程编辑器支持整段文本批量解析生成日程，并改为紧凑列表 + 内部滚动呈现。

## 背景

管理员维护会议日程时，逐条添加时段与环节、填写时间、标题、富文本内容和地点，操作繁琐。实际日程文本常以「时间 Tab 标题 Tab 内容」的整段形式存在（如会议通知、Word 表格复制内容），且内容可能跨多行。经用户确认：

- 只改动管理员端日程编辑器，嘉宾端呈现不变。
- 使用纯规则解析（不引入外部 AI 能力），支持用户提供的真实文本格式。
- 创建好的日程以紧凑列表形式呈现，内容较多时提供内部滚动。

## 真实文本格式样例

```
09:00–09:50	开幕致辞	卫新（苏州中学书记）
苏州市教育局领导（待定）
熊斌 教授（华东师范大学）（待定）
09:50–10:20	主题演讲	葛军 教授（南京师范大学）
10:20–10:40	学校分享	大连市第二十四中学代表
演讲主题：拔尖创新人才早期培养的实践与思考
10:40–11:00	茶歇	—
```

特征：Tab 分隔三列；时间段使用短横线连接；内容可跨多行；`—` 表示无内容；无日期行与时段行。

## 执行前必须读取

## 目标

- 日程编辑器新增「粘贴整段日程」入口：粘贴文本 → 规则解析 → 预览结果（含未识别行提示）→ 覆盖或追加写入。
- 解析规则兼容 Tab、竖线分隔；全角冒号；短横线、至等多种时间连接符；跨行内容续行；`—` 占位符；无日期行时归属会议开始日期，无时段行时按开始时间自动归组。
- 编辑器右侧改为紧凑环节列表：每行显示时间、标题、地点，点击展开编辑详情；日程区域固定高度内部滚动。
- 后端接口与正文存储格式不变；前端构建通过，文档同步更新。

## 不在本次范围内的内容

- 嘉宾端日程呈现不做改动。
- 不引入外部智能解析服务。
- 不改动现有编辑器已保存的正文格式与解析逻辑（历史内容兼容不变）。

## 分步计划

1. 编写本执行计划。
2. 在 `AdminAgendaEditor.vue` 新增批量解析函数：支持 Tab / 竖线分隔、全角冒号、时间连接符、跨行续行、占位符、自动日期与时段归属，并输出未识别行。
3. 新增「粘贴整段日程」弹窗：多行输入、解析预览、覆盖 / 追加选择、写入确认。
4. 改造右侧编辑区为紧凑列表：环节行默认收起显示时间、标题、地点，点击展开完整编辑表单；日程区域内部滚动，日期列表同步可滚动。
5. 验证：前端 `npm run build` 通过，手工粘贴样例文本核对解析结果。

## 验收标准

- 粘贴用户提供的真实格式文本，能正确拆分为 8 条环节，发言人跨行内容完整保留，`—` 不产生空内容。
- 预览界面展示识别条数、归属日期与时段，并列出未识别行。
- 覆盖与追加两种写入方式正确：覆盖替换全部日程，追加合并到同日期同名时段末尾。
- 右侧环节列表默认紧凑显示，点击可展开编辑；环节多时列表内部滚动，弹窗不被无限撑高。
- 历史已保存日程打开后展示与编辑行为不变。

## 完成记录

实现完成，验证结果：

- 批量解析：`AdminAgendaEditor.vue` 新增「粘贴整段日程」入口与弹窗，支持 Tab / 竖线分隔、全角冒号归一、短横线等多种时间连接符、跨行内容续行、`—` 占位符置空；无日期行时归属会议开始日期，无时段行时按开始时间自动归入上午 / 中午 / 下午 / 晚上 / 全天。

- 列表化编辑：右侧环节区改为紧凑列表，每行显示时间、标题、地点与展开状态，点击展开完整编辑表单；新增环节默认展开；日程区与左侧日期列表均支持内部滚动。

- 构建：`npm run build` 通过；历史已保存正文格式与解析逻辑未改动。
