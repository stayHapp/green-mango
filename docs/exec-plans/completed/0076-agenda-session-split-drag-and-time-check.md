# 执行计划 0076：日程时段区分、拖拽排序与时间顺序校验

## 任务名称

管理员端日程编辑器按时间自动区分时段，支持环节与时段拖拽排序，并对时间顺序异常给出提示。

## 背景

批量粘贴解析日程时，环节已按开始时间自动归入上午 / 中午 / 下午 / 晚上 / 全天时段，但管理员仍需要：

- 解析与编辑时能按时间清晰区分时段；
- 通过拖动调整环节顺序，且允许把环节拖到其他时段（如把临近中午的环节拖入「中午」）；
- 环节时间顺序不对（乱序或重叠）时给出明确提示，避免嘉宾端展示错乱。

经确认仅改动管理员端日程编辑器，不引入第三方拖拽库，使用浏览器原生拖拽能力实现。

## 执行前必须读取

- `AGENTS.md`（禁止未经确认引入新框架，因此使用原生 HTML5 拖拽）
- `docs/product/meeting-assistant.md`

## 目标

- 环节行可拖拽排序：同一时段内调整顺序，也可跨时段拖入其他时段；拖动过程有高亮反馈。
- 时段卡片可拖拽排序，调整上午 / 中午 / 下午等展示顺序。
- 时段内相邻环节时间乱序（开始时间早于上一条开始时间）或重叠（开始时间早于上一条结束时间）时，环节行显示中文提示。
- 批量解析预览同样按时间分时段展示，并在预览中标记顺序异常条目。

## 不在本次范围内的内容

- 不改变嘉宾端日程展示逻辑。
- 不引入 sortablejs / vuedraggable 等第三方依赖。
- 不自动修正时间，只做提示与手动拖动调整。

## 分步计划

4. 新增时间顺序校验函数：判断时段内相邻环节乱序或重叠，环节行与解析预览中显示提示。

## 验收标准

- 环节可拖入同一时段其他位置或另一时段，拖动目标位置有高亮，释放后顺序与归属正确。
- 时段可拖动排序，顺序变化持久化到序列化正文。
- 同一时段内环节开始时间早于上一条或与上一条重叠时，对应行显示中文提示；调整后提示消失。
- 解析预览按时段分组，顺序异常条目带提示。

## 完成记录

实现完成，验证结果：

- 时段区分：批量解析继续按开始时间自动归入上午 / 中午 / 下午 / 晚上 / 全天时段，预览与编辑器按时段分组展示。
- 环节拖拽：使用浏览器原生拖拽实现，环节行可拖入同一时段其他位置或跨时段拖入其他时段，拖动时目标行虚线高亮，释放后顺序与归属正确。
- 时段排序：时段头部新增拖拽把手，可拖动调整时段顺序；上移 / 下移按钮保留。
- 时间校验：新增 `entryTimeIssue`，时段内相邻环节开始时间早于上一条开始时间提示「时间顺序异常」，早于上一条结束时间提示「时间重叠」；编辑器环节行与批量解析预览均展示提示，调整时间或顺序后自动消失。
- 依赖：未引入第三方拖拽库，使用原生 HTML5 拖拽 API。
- 构建：`npm run build` 通过；校验逻辑经脚本验证乱序、重叠、正常三种场景输出正确。
